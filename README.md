# AgroTech - платформа мониторинга животноводческих ферм

Архитектурный проект системы мониторинга скота для компании "АгроПром Х".
Решение построено на распределённой архитектуре "центральная платформа - локальные системы
мониторинга": критичные к задержке и доступности интернета функции (видеоаналитика,
аутентификация, управление оборудованием) работают локально на каждой ферме, а аналитические
и интеграционные - на центральной платформе. Все решения оформлены как ADR, диаграммы
подготовлены в нотации C4.

## Как читать артефакты

Решение каждой задачи содержит ADR-файл (`ADR.md`) и диаграммы в нотации C4.
В ADR описываются контекст, функциональные и нефункциональные требования, выбранное решение,
рассмотренные альтернативы и связанные риски; в задаче 4 дополнительно приведено сравнение
основного и альтернативного решений по критериям. Диаграммы представлены исходником PlantUML
(`.puml`) и готовым рендером (`.png`).
